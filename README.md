# 🤖 AI Watercooler Gossip

> *"Wanna know what everyone says behind your back? Who knows you better than your AI?"*

A zero-prompt, model-agnostic skill compatible with **Gemini**, **ChatGPT**, **Claude Projects**, **Cursor Rules**, and **MCP/Agentic tools**. 

Once installed, just type `/gossip` and your AI will immediately start spilling the tea with a fellow model about your quirks, side projects, and habits.

---

## ⚠️ Crucial Prerequisite: Active Memory Required

For this skill to generate sharp, hyper-personalized tea instead of generic filler, **persistent memory must be enabled** (or supplied via custom instructions/profile):

- **Gemini**: Persistent Memory / Personal Intelligence turned ON.
- **ChatGPT**: Memory (`Settings > Personalization > Memory`) enabled.
- **Claude**: Added to Project Knowledge or Custom Instructions.
- **Cursor / Copilot**: Added to `.cursorrules` or system prompt.

*If the model has no memory of you, it will refuse to gossip until you feed it some data.*

---

## 🚀 Installation & Usage

### 1. Install the Skill
- **ChatGPT**: Create a custom GPT or add the text from [`SKILL.md`](./SKILL.md) into your **Custom Instructions**.
- **Gemini**: Create a Gem and paste the contents of [`SKILL.md`](./SKILL.md) into the instructions.
- **Cursor / Agents**: Drop [`SKILL.md`](./SKILL.md) into your skills directory or `.cursorrules`.

### 2. Run It
No long prompts needed. Just send:

```text
/gossip
